AI-Powered LinkedIn Post Generator

n8n Docker LinkedIn API Google Drive API Google Sheets Gemini AI

Overview

A containerized, human-in-the-loop content automation system deployed via n8n and Docker. The workflow ingests structured topic ideas from Google Sheets, generates contextual post drafts using Google Gemini, and waits for explicit user modification and approval. Upon confirmation, it retrieves linked media assets from Google Drive and publishes directly through authorized LinkedIn APIs.

What It Does

  • > Ingests structured content prompts and schedule metadata from Google Sheets.
  • > Generates professional drafts via Gemini AI with customized prompt instructions.
  • > Implements an approval-based workflow supporting manual review and iterative refinement.
  • > Fetches matching image assets from Google Drive and publishes via LinkedIn API.
